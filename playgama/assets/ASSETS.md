# Publishing asset inventory

Use these files for the cover slots and other resources in the publishing form. Paths are relative to this directory.

## Covers

| Slot | Size | Upload file |
| --- | --- | --- |
| Square | 800 × 800 | [Square cover](covers/city-ride-square-800x800.png) |
| Portrait | 1080 × 1920 | [Portrait cover](covers/city-ride-portrait-1080x1920.png) |
| Landscape | 1920 × 1080 | [Landscape cover](covers/city-ride-landscape-1920x1080.png) |

These are promotional key art. The workspace's `covers/source/` folder contains original generated artwork for future revisions; originals are excluded from the publishing ZIP. Use the exact-size PNGs above for upload.
