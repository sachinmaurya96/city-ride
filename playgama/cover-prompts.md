# Cover artwork prompts

Created with the built-in image generation tool. Each aspect ratio has its own composition, referenced to the game's existing black Lamborghini Huracán and yellow McLaren P1 screenshots. Final PNGs were resampled to the exact publishing dimensions with macOS `sips`.

## square

Use case: ads-marketing. Create premium publishing cover key art for the actual browser game CITY RIDE. Input image 1: visual reference for the black Lamborghini Huracan with yellow side graphics. Input image 2: visual reference for the yellow-and-green McLaren P1 GTR. Preserve their recognizable proportions, wheel/body details and paint colors. Use the reference game's sunny 3D city boulevard, dark glass apartment towers, palms, cream sidewalks, marked asphalt and clear blue sky. Stylized polished game key art, attractive and readable at thumbnail scale, believable clean 3D materials, crisp car silhouettes, dramatic low three-quarter automotive framing, vivid controlled colors. It must look like an appealing illustration of this game, not a photoreal photograph. No UI, watermark, platform logo, racing opponents, destruction, weapons, people or unsupported gameplay. The only text is the exact title "CITY RIDE", large bold premium italic automotive lettering, clean white with a subtle blue depth/accent, legible and fully inside the safe area. No subtitle. Square 1:1 composition, 800 by 800 pixel final cover. Title in the upper quarter with generous margins. Black Lamborghini hero in the foreground lower two thirds, yellow McLaren secondary behind it. Both complete cars visible, no cut off bumpers or wheels. Distinct balanced square composition, not a crop of a horizontal image.
